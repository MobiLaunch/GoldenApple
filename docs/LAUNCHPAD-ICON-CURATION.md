# Golden Gate — automatic macOS-style application icon curation

## Launchpad rule

**Only applications with an approved Golden Gate or matching open-source
macOS-style application icon are displayed in Launchpad.** There is no
"Other" folder for apps with ordinary Linux, generic or missing icons.
Launchpad search and its Utilities folder use the same allowlist. An
unmatched app is **not uninstalled, disabled or blocked**: it remains
available through Files, command line, desktop application pickers,
file associations and the normal running-app Dock.

Icons must correspond to the actual application identity (desktop ID or
its declared icon name). Names are matched exactly, then in lowercase.
There is no fuzzy search, guessed screenshot, automatic unrelated
app substitution, or arbitrary upstream image generation.

Built-in Golden Gate apps keep the icons already generated by
\`icons/build.mjs\` and preserve their existing calendar badge artwork.

## Open-source artwork: WhiteSur (GPL-3.0)

The [WhiteSur icon project](https://github.com/vinceliuice/WhiteSur-icon-theme)
provides macOS Big Sur-style artwork and actual freedesktop
app aliases. The resolver uses its pinned \`2026-09-10\` release;
the icon file and alias must be present in that upstream repository.

At first sign-in, \`gg-icon-resolver watch\` bootstraps an index of the
open-source application SVGs into the user's
\`~/.cache/golden-gate/icon-packs/whitesur\` and preserves the upstream
\`COPYING\` license. The resolver downloads only from a pinned GitHub tag
and **never runs the upstream installer**. It allows only validated SVG
members under \`src/apps/scalable\` and their safe \`links/apps/scalable\`
aliases. It rejects scripts, external resource references and links that
escape the package. Icons can contain self-contained PNG/JPEG data URIs.

To avoid a new font or asset distribution restriction, the official
Golden Gate icon source remains its own original work, and WhiteSur is a
separately cached and attributed GPL-3.0 third-party icon pack. If
network access is unavailable or the icon pack is removed, the fallback
is **hide unmatched apps**, not display arbitrary icons.

## Installation detection

The App Store calls \`gg-icon-resolver bootstrap\` after a successful
Flatpak install, and \`gg-icon-resolver sync\` after an update/removal.
A missing icon does not roll back a successful app install.

The compositor launches \`gg-icon-resolver watch\` once at sign-in.
The process uses Linux inotify to detect new and changed desktop entries
in system, user and Flatpak export directories and reindexes them after
the installer finishes writing. A slow fallback refresh checks for
changes in previously missing directories without keeping the
Quickshell rendering loop busy.

The result is a validated JSON manifest at
\`~/.cache/golden-gate/launchpad-icons.json\` with desktop IDs and absolute,
local icon paths. Both Launchpad and the Dock consume it. The manifest
is atomically replaced only when the selection changes; the reader watches
it, and Launchpad keeps its open-state grid stable to avoid jumpy icon
layouts during an install.

\`gg-icon-resolver sync\` does an offline rescan, and
\`gg-icon-resolver bootstrap\` tries to fetch the open-source pack first.
To force a rescan after installing software from pacman or elsewhere:

\`\`\`sh
gg-icon-resolver bootstrap
\`\`\`

For an individual app to match, its desktop entry should declare the
real application ID or a recognized freedesktop icon name. It is not
enough to ship a generic \`application-x-executable\` icon.

## Current limitations

- Source pack is macOS **inspired**, not a complete set of exact
  proprietary Apple icons for every third-party Linux app.
- A newly installed app is not guaranteed to have a match, even if it
  has an icon on an unrelated repository outside the approved catalog.
- WhiteSur pack download needs network access once; first sign-in may
  have no third-party matches until the download completes. No app is
  blocked or deleted because of network availability.
- The resolver supplies consistent artwork specifically to Launchpad
  and the Dock; it **does not rewrite vendor .desktop files or override**
  arbitrary GTK/Qt icon choices throughout the entire OS.
- New desktop entries are indexed without continuous GPU polling. A
  Launchpad page already open is snapshotted; reopen it after an install
  to see the new app in its stable page layout.

## Tests

\`python tests/icon-resolver.py\` tests a fake GPL source archive without
network access, including alias resolution, embedded raster data,
unsafe SVG rejection, first-party retention, unmatched app filtering,
app removal and the App Store/installer integration.
