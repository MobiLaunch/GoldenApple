## Fixed

| Finding | Change | Evidence |
| --- | --- | --- |
| TextEdit saved the current editor text as its baseline after an asynchronous save, even when a newer revision had never reached disk. | Capture the exact text/path before starting the write; compare the live editor to that snapshot on completion. | Qt regression edits again before the save response; the new edit remains dirty. |
| Opening an unreadable document changed the active path while retaining the old draft. A subsequent save could target the wrong file. | Commit the new path only after a successful read; prevent overlapping open/save operations. | Qt regression verifies a failed open preserves both path and draft. |
| New TextEdit documents had no working Save As path. New/Open/close discarded unsaved text. | Native open/save pickers; unsaved-change guard on New/Open and window close; Ctrl+Q now honors AppWindow's close action. | Native app load and editor lifecycle tests. Explicit compositor termination/log out is still outside this guard. |
| TextEdit used a predictable temporary filename, reset private file permissions and replaced symlinks. Invalid UTF-8 was silently replaced. | Unique atomic temp files, existing permissions retained, symlink targets resolved, strict UTF-8 reads. | Native backend tests cover private files, symlinks and invalid bytes. |
| Shared multiline editors lacked a right-click edit menu. | Shared Cut/Copy/Paste/Select All menu and lazy Writing Tools action, with read-only/empty states respected. | Qt selection/undo/read-only/stale-document tests. |
| Empty Trash crashed without `gio`, returning no JSON even though home Trash had already been emptied. | Structured success with a warning when gio is missing; bounded handling of launch/time-out failures. | Existing Files backend suite now passes without gio. |
| Eleven CI guards still searched old one-line QML, legacy labels, embedded Dock identities and a moved tint literal. | Guards now follow the current component structure, central preferences and theme tokens. | All commands in the login/glass guard step pass against the current source. |
| README still called the removed Dock magnification a current feature. | Describe the current iPad-style Dock. | Checked against Dock implementation. |
